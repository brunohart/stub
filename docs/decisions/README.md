# Decisions

The record behind the case study. One file per decision; each says **the decision**, **the evidence** it rests on, and
**what was killed** to make room for it. `DECISIONS.md` at the root stays the engineering log (ADR-001 onwards, how a
thing was built); this folder is the product record (why it exists at all, and what it cost).

An entry is never rewritten to look right later. If a decision is reversed, a new entry says so and links back.
